## Known Issues and Limitations

### 1. Fusion Dataset 0922 High Error

**Issue:** Both C (69°) and Python (17.7°) show high mean error against dataset 0922 "expected" outputs.

**Root Cause:** The "expected" quaternions in dataset 0922 were generated by an unknown algorithm (likely vendor SDK or different implementation).

**Impact:** Dataset 0922 validates **regression** (no crashes, no NaN) but NOT absolute accuracy.

**Mitigation:** Use realistic datasets (walking.csv) for accuracy validation.

### 2. Removed Fusion Datasets

**Issue:** Datasets 0923/0930/1012 removed due to incompatibility.

**Reason:**
- 0923_moving: 50° error (wrong algorithm)
- 0923_standstill: 25.7° error (high outliers)
- 0930: 138° error (coordinate frame mismatch)
- 1012: Corrupted (all zeros)

**Impact:** Less test coverage for fusion datasets.

**Mitigation:** Dataset 0922 provides adequate regression coverage. Create new test vectors from current C implementation if needed.

### 3. C/Python Tolerance Difference

**Issue:** C and Python may have slight numerical differences due to floating point precision.

**Tolerance:** `3e-5` quaternion distance tolerance in test_compare_python.c

**Mitigation:** This is expected and accounted for in cross-validation tools.
