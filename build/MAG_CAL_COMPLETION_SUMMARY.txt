STEP 3: Enhanced SVD Algorithm ✅
========================================

Files Created:
- algo_sf_mag_cal_svd.c - Improved calibration algorithm

Enhancements:
- Uses centroid instead of bounding box for hard iron
- Computes covariance matrix of centered samples
- Applies eigendecomposition for soft iron matrix
- Improved quality metric calculation

Algorithm:
1. Compute center using centroid (mean of samples)
2. Build covariance matrix of centered samples
3. Compute M^{-1/2} using eigendecomposition
4. Use as soft iron correction matrix
