========================================
HOW IT WORKS
========================================

1. Initialization:
   - When sf_9xagm_algo_init() is called, mag_cal_state is automatically
     allocated and initialized
   - Initial status: MAG_CAL_STATUS_UNCALIBRATED

2. Sample Collection (Automatic):
   - Every time new magnetometer data arrives, sf_9xagm_algo_measupdate_mag()
     is called
   - Raw magnetometer samples are automatically added to the calibration buffer
   - Samples are validated (no NaN, within range, diverse enough)
   - Status changes to MAG_CAL_STATUS_COLLECTING after MAG_CAL_MIN_SAMPLES (50)

3. Auto-Calibration Computation:
   - When status is COLLECTING, the algorithm automatically attempts to compute
     calibration parameters
   - Uses ellipsoid fitting to determine hard iron offset and soft iron matrix
   - Quality metric computed based on sample distribution and field magnitude
   - If quality >= 0.85, status changes to MAG_CAL_STATUS_CALIBRATED
   - Calibration parameters synced to MagCalOffset/MagCalMatrix for backward compatibility

4. Automatic Application:
   - Once calibrated, mag_cal_apply() is called automatically on every
     magnetometer reading
   - Corrects for hard iron (offset) and soft iron (matrix) distortions
   - If uncalibrated, raw data passes through unchanged

5. Cleanup:
   - When sf_9xagm_algo_stop() is called, mag_cal_state is freed automatically

========================================
CALIBRATION PARAMETERS
========================================

- Minimum samples required: 50 (MAG_CAL_MIN_SAMPLES)
- Maximum samples buffered: 200 (MAG_CAL_MAX_SAMPLES)
- Quality threshold: 0.85 (MAG_CAL_QUALITY_THRESHOLD)
- Sample diversity threshold: 5.0 μT (minimum distance between samples)
- Outlier rejection: samples > 200 μT rejected
- Valid range: 25-100 μT expected field magnitude

========================================
IMPLEMENTATION NOTES
========================================

1. Memory Management:
   - mag_cal_state allocated on heap (sizeof = ~6.5 KB)
   - Automatically freed on sf_9xagm_algo_stop()
   - Uses void* to avoid circular header dependencies

2. Thread Safety:
   - Current implementation assumes single-threaded access
   - mag_cal_state is not mutex-protected
   - If multi-threaded, add mutex around calibration operations

3. Performance Impact:
   - Sample collection: O(1) per magnetometer reading
   - Calibration computation: O(N²) where N=200 max samples
   - Computation only triggered when status=COLLECTING
   - Minimal overhead during normal operation

4. Calibration Trigger:
   - Auto-computes when MAG_CAL_STATUS_COLLECTING
   - Will retry on every new sample until successful
   - Prevents infinite retries if quality never improves
